# Android deploy

Builds this Expo project and installs it on a connected Android device or emulator.

App package: `com.anonymous.simplefoodscanner`. The `android/` directory is gitignored and generated by prebuild, so it may be missing on a fresh clone — `expo run:android` regenerates it automatically.

## 1. Check the device

```bash
adb devices -l
```

- No devices: tell the user to connect the phone via USB with USB debugging enabled (or start an emulator) and stop.
- `unauthorized`: the user must accept the RSA prompt on the phone.
- Multiple devices: run `npx expo run:android --device` with no value — Expo prints a picker of device names. Do not pass the adb serial to `--device`; Expo matches on device name and fails with `CommandError: Could not find device with name: <serial>`. With exactly one device attached, omit the flag entirely.

If `adb` is not on PATH, use `~/Library/Android/sdk/platform-tools/adb`.

## 2. Pick the right path

**JS/TS-only change and the app is already installed** — no rebuild needed. Start the bundler and let Fast Refresh do the work:

```bash
npx expo start --dev-client
```

Only fall through to a full build if the user explicitly wants a fresh install or the app is not installed yet.

**Native change** — new native dependency, edits to `app.json`, plugin config, permissions, app icon, or the app was never installed. Full build:

```bash
npx expo run:android
```

Release build (signed with the debug keystore unless a release keystore is configured):

```bash
npx expo run:android --variant release
```

Run builds in the background — a cold Gradle build takes several minutes. Report the failing Gradle task and its error lines if it fails, not the whole log.

## 3. Verify

```bash
adb -s <serial> shell pm list packages | grep simplefoodscanner
```

`expo run:android` launches the app itself. To relaunch manually:

```bash
adb -s <serial> shell monkey -p com.anonymous.simplefoodscanner -c android.intent.category.LAUNCHER 1
```

## Troubleshooting

- `INSTALL_FAILED_UPDATE_INCOMPATIBLE` / signature mismatch — the installed build was signed with a different key. Confirm with the user first (this wipes the app's local SQLite data), then `adb -s <serial> uninstall com.anonymous.simplefoodscanner` and rebuild.
- App installs but can't reach the bundler over USB: `adb -s <serial> reverse tcp:8081 tcp:8081`.
- Port 8081 already in use: `npx expo start --port 8082` or kill the stale process.
- Gradle failures after dependency or config changes: `npx expo prebuild --platform android --clean`, then rebuild. This discards manual edits under `android/`.
- Stale build artifacts: `cd android && ./gradlew clean`.
- Only reinstalling an existing APK without rebuilding: `cd android && ./gradlew installDebug`.
